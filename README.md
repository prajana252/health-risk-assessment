# Vitala AI — Health Intelligence Snapshot

A static, GitHub Pages-compatible educational prototype.

## Features
- Clickable overview, assessment and visual report navigation
- Four-step input flow with validation and a review-before-results screen
- Visual completeness ring, BMI estimate, input-by-input observation cards and tailored general prompts
- Clear missing-data states, explanations and limitations
- Export a text summary and print / save the report as PDF
- Responsive dark navy, blue and violet interface

## Run locally
Open `index.html` in a modern browser. No build step or backend is required.

## Publish to GitHub Pages
Upload the contents of this folder to the repository root, commit changes, and ensure Pages publishes from the intended branch and root folder.

## Safety and privacy
Educational prototype only. It is not a medical device, diagnosis, or clinically validated risk prediction. It uses simple reference explanations and user-entered values, not an AI model or validated clinical risk calculator. It does not transmit data to a server; values are held in page memory only. Do not use it for urgent symptoms or treatment decisions.
